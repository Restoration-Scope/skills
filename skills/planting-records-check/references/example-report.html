Behind the four tests

ARTICLEExhaustive, Complete, Correct, CurrentREAD

A full sheet can still miss what matters. Four tests, in order, find the gaps while there is still time to fix them.

Fix first

  1. No stable ID for each planter.Give each planter an ID and use it in the log.
  2. Areas are planned, not planted.Mark the planted edge of each area on the next planting day.
  3. Survival counts have no date or planting.Add the visit date, area ID and planting date to each count.

Only your team can answer

  • Is "North block" in the log the same place as area A2 on the map?
  • On the 3 days where species counts and the day total differ, which is right?
  • Was anything planted in area A6?
